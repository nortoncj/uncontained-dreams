Delivery

Built in Texas. Delivered to all 50 states.

Every home ships on a flatbed and is set in place by crane. The first 1,000 miles are included. Past that, we quote delivery before you sign, so the freight bill never shows up as a surprise.

Canada, the U.S. Virgin Islands, and other international destinations are quoted case by case.

Permits and zoning

Check your zoning first. We'll help you do it.

Rules for container homes change by city, county, and HOA. Some places treat them like any home, some like an ADU, and a few don't allow them at all.
